# Security Policy

## Scope

This repository contains educational cybersecurity labs, detection examples, synthetic analytics, and documentation. It is not intended to contain production credentials, private customer information, or confidential employer data.

## Reporting a sensitive issue

If you discover a credential, private information, or another sensitive security issue accidentally committed to this repository, please do not reproduce or redistribute it in an issue. Contact me privately through the contact details on my GitHub or LinkedIn profile so the material can be removed and any exposed credential can be rotated.

## Responsible use

Lab material is intended for systems you own or are explicitly authorized to test. Examples should be run in isolated environments and adapted to the controls and policies of the relevant organisation.
